IsVirtual

Whether this peer describes something that is not a control — a virtualized list row, a menu entry — and therefore has to be published by its owner.

The tree walk reaches real controls on its own, so publishing those twice would list every control once as a child and once as a peer. Virtual peers are the ones with no control to be reached through.
