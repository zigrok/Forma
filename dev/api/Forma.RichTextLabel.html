Lightweight BBCode label with styled text runs. It intentionally concentrates on the common authoring tags (b, i, u, s/strike, color, and br) while preserving the retained Control model and plain-text Text projection.

[TemplatePart("PART_RichTextPresenter", typeof(Container), true)]
