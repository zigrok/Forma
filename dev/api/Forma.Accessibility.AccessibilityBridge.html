Remarks

Opt-in. An application creates one, attaches it to its window, and calls Update() each frame. Everything is a no-op until an assistive technology actually activates the tree, so a running bridge costs one native call per frame.

Attach(nint) answering false is a normal outcome, not a failure to handle: it means this platform has no host, there is no window (a headless runtime), or the native library is missing. The application carries on exactly as it did before. 

_accessibility = new AccessibilityBridge(_ui) { WindowTitle = Window.Title };
_accessibility.Attach(Window.PlatformHandle);
// ... each frame, after layout:
_accessibility.Update();
