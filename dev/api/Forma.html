Owns one detached popup and its compiled control lifetime. Construct, open, accept, cancel and dispose on the context's creation thread. Token callbacks only latch; Update drains cancellation. Acceptance linearizes under the same lock as cancellation, after result validation. A cancellation already signalled at that point wins. Cleanup precedes completion; cleanup failure faults it. Context disposal terminates even an unopened session and prevents further session reservations. The caller supplies result validation and is responsible for immutable result ownership.
