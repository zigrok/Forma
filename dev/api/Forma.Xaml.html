Localization

The data-i18n convention (as i18next's DOM bindings use): controls authored with data-i18n="menu.play" carry the key as the data attribute i18n; Apply(Control, Func<string, string>) sets their text from a translation function, and is called again when the language changes. data-i18n-placeholder, data-i18n-label and data-i18n-title localize the placeholder, the accessibility label and the title the same way.

PseudoLocaleOptions

Options for PseudoLocalizer.

PseudoLocalizer

A pseudo-locale for layout stress tests: every string is accented, wrapped in markers and made longer, so a layout that only fits the source language fails in a test before a real translation exists. Output is deterministic, and placeholders such as {0} or {name} are copied verbatim. It is a testing and tooling feature; it is never a shipped language.

ThemeResources

Applies a named theme to a view's resources. The HTML and CSS dialect emits a token's overrides as name@theme resources (from :root[data-theme="dark"] or @media (prefers-color-scheme: dark)) and its original value as name@default; Apply(Control, string) copies the chosen set over the base keys, so every live var(--name) follows, and records the theme as the root's data-theme attribute so [data-theme="dark"] selectors match.
