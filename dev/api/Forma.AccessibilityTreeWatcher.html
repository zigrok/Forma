Tracks whether the accessibility tree could have changed, so consumers re-capture on a signal instead of walking the whole tree every frame.

Deliberately conservative: it reports possible change, never certainty. A control raising AccessibilityChanged may have changed something the snapshot does not carry, in which case the diff simply comes back empty — cheap, and far safer than missing a real change.
