Text input controls

Use LineEdit for one line and IME-aware entry, TextEdit for multiline editing, and SpinBox for numeric text with stepping. LineEditPresenter and SpinBoxLineEdit are template/owner infrastructure; application views normally use their owning controls.

Type Selection note
LineEdit Single line, selection, clipboard, placeholder, submission, and text binding
TextEdit Multiline editing, carets, gutters, wrapping, and scrolling
SpinBox Numeric range editing with increment/decrement controls
LineEditPresenter Template presenter for line-edit rendering and interaction
SpinBoxLineEdit Owner-created editor used by SpinBox

LineEdit starts empty, is keyboard-focusable, and has 6,4,6,4 padding. Host text-input forwarding is required for composed/IME text; do not convert key codes to characters. SpinBox normally commits edited text on submission because UpdateOnTextChanged defaults to false. Its ArrowLayout defaults to Vertical, with stacked arrows on the right. Set ArrowLayout="Horizontal" in XAML for a full-height decrement button on the left and increment button on the right around the editor.

Text editors expose a text-box accessibility role, current value, selection/edit actions, and a read-only state when editing is disabled. SpinBox exposes the spin-button role and range actions. Give an explicit AccessibilityLabel when the nearby visual label is not represented by the host's accessibility bridge.

Catalog: LineEdit, TextEdit, SpinBox. See Input and focus and Data binding.

Every public type in the table has a Catalog story with the exact unqualified type name. Its stable identifier is catalog- plus the kebab-case type name, such as catalog-line-edit; the Catalog's Open reference link returns to this page.
