Selection controls

Type Use
CheckBox, CheckButton Boolean state with check or switch presentation
OptionButton One value from a compact option set
Range Abstract scalar-value behavior shared by range controls
Slider, HSlider, VSlider Continuous or stepped scalar selection
TabBar Select a page header; pair with TabContainer for page ownership
ColorPicker Detailed color selection
VirtualJoystick Normalized two-axis pointer/touch input

Range defaults to minimum 0, maximum 100, step 1, and clamping; enable AllowGreater or AllowLesser only when values outside the displayed interval are intentional. Sliders expose increment, decrement, and set-value actions. Checks, options, tabs, colors, and joysticks specialize their accessibility roles and state; do not replace them with unlabeled generic buttons.

Catalog: OptionButton, TabBar, ColorPicker, VirtualJoystick.

Every public type in the table has a Catalog story with the exact unqualified type name. Its stable identifier is catalog- plus the kebab-case type name, such as catalog-option-button; the Catalog's Open reference link returns to this page.
