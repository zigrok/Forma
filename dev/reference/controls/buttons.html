Button controls

Start with Button for ordinary commands. Use a specialized control only when its semantics or rendering match the interaction.

Type Use
BaseButton Base behavior for a custom button control
Button Text/icon command
LinkButton Link-like action with link accessibility semantics
MenuButton Command that owns a popup menu
TextureButton Texture-state command and optional click mask
ColorPickerButton Opens color selection for a current color
ColorPresetButton Selects one preset color

Button behavior defaults to keyboard focus, release activation, left-pointer activation, and non-toggle mode. Text is centered by default. Enter and Space activate a focused button. Choose toggle behavior only for persistent state; for standard Boolean settings prefer CheckBox or CheckButton.

Buttons expose press actions, button/link roles, optional toggle actions, and checked state. Preserve visible focus and a meaningful accessibility name when replacing the default template.

Catalog: Button, LinkButton, TextureButton, MenuButton.

Every public type in the table has a Catalog story with the exact unqualified type name. Its stable identifier is catalog- plus the kebab-case type name, such as catalog-base-button; the Catalog's Open reference link returns to this page.
