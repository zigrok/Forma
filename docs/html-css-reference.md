# HTML and CSS dialect reference

Generated by `forma-xaml docs` from the catalog the converter tests compile; do not edit.

## div (plain)

Lowers to `Container`.

```html
<div><span>x</span></div>
```

## div (display: flex, row)

Lowers to `HBoxContainer`.

```html
<div style="display: flex; gap: 4px"><span>a</span><span>b</span></div>
```

## div (display: flex, column)

Lowers to `VBoxContainer`.

```html
<div style="display: flex; flex-direction: column; gap: 4px"><span>a</span></div>
```

## div (padding, border, background)

Lowers to `Border`.

```html
<div style="padding: 4px; border-width: 1px; background-color: #112233"><span>a</span></div>
```

## div (display: grid)


## CSS properties

- `display`: `display: flex` (flex, grid, block or none)
- `flex-direction`: `display: flex; flex-direction: column` (row or column)
- `flex-wrap`: `display: flex; flex-wrap: wrap` (nowrap or wrap (flow container))
- `gap`: `display: flex; gap: 8px` (flex containers and grids)
- `justify-content`: `display: flex; justify-content: center` (start, center, end)
- `align-items`: `display: flex; align-items: center` (start, center, end, stretch)
- `align-self`: `align-self: center` (start, center, end, stretch)
- `flex-grow`: `flex-grow: 1` (needs a flex parent)
- `flex`: `flex: 1` (1, auto, 0, none)
- `vertical-align`: `vertical-align: middle` (top, middle, bottom)
- `text-align`: `text-align: center` (left, center, right)
- `width`: `width: 120px` (fixed size (minimum and maximum))
- `height`: `height: 40px` (fixed size (minimum and maximum))
- `min-width`: `min-width: 120px` (px or rem)
- `min-height`: `min-height: 40px` (px or rem)
- `max-width`: `max-width: 300px` (px or rem)
- `max-height`: `max-height: 300px` (px or rem)
- `margin`: `margin: 4px 8px` (one to four lengths; margin-top/right/bottom/left too)
- `padding`: `padding: 4px 8px` (on a flex or grid element it wraps the container in a Border)
- `border-width`: `border-width: 1px` (one to four lengths)
- `border-color`: `border-color: #33CDFF` (#RRGGBB or #RRGGBBAA)
- `border-radius`: `border-radius: 3px` (one to four radii)
- `background-color`: `background-color: #112233` (#RRGGBB or #RRGGBBAA)
- `background`: `background: linear-gradient(180deg, #000000, #FFFFFF)` (linear-gradient and radial-gradient)
- `color`: `color: #E0F8FF` (text color)
- `font-size`: `font-size: 24px` (px or rem)
- `font-weight`: `font-weight: bold` (normal, bold, 400, 700)
- `font-style`: `font-style: italic` (normal, italic, oblique)
- `opacity`: `opacity: 0.5` (0 to 1)
- `overflow`: `overflow: hidden` (hidden clips; wrap in f-scroll to scroll)
- `box-shadow`: `box-shadow: 0 2px 4px #80000000` (x y [blur [spread]] color [inset])
- `text-shadow`: `text-shadow: 1px 1px #000000` (x y color (blur is not drawn))
- `text-transform`: `text-transform: uppercase` (uppercase or none)
- `text-overflow`: `text-overflow: ellipsis` (ellipsis or clip)
- `white-space`: `white-space: nowrap` (nowrap or normal)
- `transform`: `transform: scale(1.1)` (translate(), scale(), rotate())
- `transform-origin`: `transform-origin: 50% 50%` (keywords and percentages)
- `pointer-events`: `pointer-events: none` (none or auto)
- `transition`: `transition: opacity 150ms` (property and duration)
- `box-sizing`: `box-sizing: border-box` (border-box only)
- `grid-template-columns`: `display: grid; grid-template-columns: 1fr 2fr` (px and fr tracks)
