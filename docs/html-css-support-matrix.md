## Replacing f: properties

`f:Property="value"` sets any Forma property verbatim, but most have an HTML or CSS spelling. Use it first; `bind:<property-in-kebab-case>` binds any Forma property to a view-model path. `forma-xaml validate` prints an `FHTML3001` hint when an `f:` attribute has a spelling listed here.

| f: property | Use instead | Example | Note |
| --- | --- | --- | --- |
| `f:FontColor` | `bind:font-color="Path"` | `<span bind:font-color="NameColor"></span>` | A color from the view model. A fixed color is the CSS `color` property. |
| `f:AccessibilityLabel` | `aria-label="Text"` | `<span aria-label="Volume"></span>` | A fixed accessible name. |
| `f:AccessibilityLabel` | `bind:accessibility-label="Path"` | `<span bind:accessibility-label="Label"></span>` | An accessible name from the view model. |
| `f:SelectedIndex` | `bind:selected-index="Path;mode=TwoWay"` | `<ul selectable bind:items="Rows" bind:selected-index="Picked;mode=TwoWay"><template data-type="local:RowModel"><span bind:text="Name"></span></template></ul>` | Any Forma property can be bound with bind:<property-in-kebab-case>. |
| `f:DataContext` | `bind:data-context="Path"` | `<f-control type="local:Panel" bind:data-context="Standings"></f-control>` | Hands a child view its own view model. |
| `f:MouseFilter` | `data-mouse="pass"` | `<div data-mouse="pass"></div>` | The control receives the mouse event and also hands it to its parent, as the children of a list row do. `stop` and `ignore` are also accepted; `pointer-events: auto \| none` is the CSS spelling of those two. |
| `f:MouseFilter` | `pointer-events: none | auto` | `<div style="pointer-events: auto"></div>` | none ignores the mouse, auto stops it (a modal backdrop). |
| `f:Margins` | `margin` | `<span style="margin: 0 12px 0 0"></span>` | One to four lengths, or margin-left, margin-top and so on. |
| `f:CustomMinimumSize` | `min-width, min-height` | `<span style="min-width: 120px; min-height: 40px"></span>` | A size from the view model stays `f:CustomMinimumSize="{Binding Size}"`. |
| `f:HorizontalAlignment` | `text-align or align-self` | `<span style="text-align: right"></span>` | text-align aligns a label's text; align-self places a control in its parent. |
| `f:HorizontalScrollMode / VerticalScrollMode / ShowVerticalStepButtons` | `data-horizontal, data-vertical, data-step-buttons on f-scroll` | `<f-scroll data-horizontal="Never" data-vertical="Always" data-step-buttons="False"><span>x</span></f-scroll>` | Values are the ScrollBarVisibility names. |
| `f:HorizontalSizeFlags / VerticalSizeFlags (main axis)` | `flex-grow: 1` | `<div style="display: flex; flex-direction: column"><span style="flex-grow: 1"></span></div>` | Shares the surplus space of a flex parent. |
| `f:HorizontalSizeFlags / VerticalSizeFlags (across the main axis)` | `data-expand="horizontal | vertical | both"` | `<div style="display: flex; flex-direction: column"><button data-expand="horizontal"></button></div>` | Takes the surplus space across the parent's main axis, as a stack of full-width buttons does. |
| `f:ZIndex` | `z-index` | `<div style="z-index: 10"></div>` | An integer. |
| `f:ActivateOnSingleClick` | `data-activate="click | double-click"` | `<ul selectable bind:items="Rows" data-activate="click"><template data-type="local:RowModel"><span bind:text="Name"></span></template></ul>` | A bound list or table activates a row on one click instead of two. |
| `f:SelectionUnit` | `data-selection-unit="row | cell"` | `<table bind:items="Rows" data-selection-unit="row"><thead><tr><th width="1*"></th></tr></thead><tbody><template data-type="local:RowModel"><tr><td><span bind:text="Name"></span></td></tr></template></tbody></table>` | What a data grid selects. |
| `f:CanUserSortColumns` | `data-sortable="true | false"` | `<table bind:items="Rows" data-sortable="false"><thead><tr><th width="1*"></th></tr></thead><tbody><template data-type="local:RowModel"><tr><td><span bind:text="Name"></span></td></tr></template></tbody></table>` | Whether column headers sort. |
| `f:CanUserResizeColumns` | `data-resizable="true | false"` | `<table bind:items="Rows" data-resizable="false"><thead><tr><th width="1*"></th></tr></thead><tbody><template data-type="local:RowModel"><tr><td><span bind:text="Name"></span></td></tr></template></tbody></table>` | Whether column edges drag. |
| `f:Flat` | `data-flat` | `<input type="text" data-flat>` | Draws a button or text field without its frame. |
| `f:MinValue / MaxValue / Step` | `min, max, step on <input type="range">` | `<input type="range" min="1" max="9" step="1">` | On a custom control that declares them, such as `<f-control type="views:SpinBox">`, `f:MinValue` stays the spelling. |

These stay `f:` properties because they have no HTML or CSS counterpart: properties of a custom control (`f:MinValue` on an application spin box), a property bound to a color or size computed in code, and any property the dialect does not name.

## Selectors

- Type, class, id, descendant and child (`>`) combinators, `:is()`, `:where()`, `:not()`; sibling combinators are rejected.
- Pseudo-classes: `:hover`, `:focus`, `:focus-visible`, `:focus-within`, `:active`, `:disabled`, `:checked`, `:selected`, `:first-child`, `:last-child`, `:only-child`, `:empty`, `:nth-child(an+b)`, `:host`.
- Attributes: `[data-*]`, `[disabled]`, `[checked]`, `[type=checkbox|range|text]`, `[role=tablist]`.
- Template parts: `::part(name)`. `ul.x li` and `table.x tr` select realized items. Other pseudo-elements are rejected.

## At-rules

- `@media (input-modality: …)`, `(prefers-reduced-motion: reduce)`, `(prefers-color-scheme: light|dark)`, `(min-width|max-width: Npx)`; `@keyframes`.
- `@import`, `@font-face`, `@supports`, `@container` and `!important` are rejected.

## Behaviors worth knowing

- `<details>` is collapsed unless it has `open`; `<summary>` is its title. `<progress>` is at least 20px high.
- Padding, border and background on a flex or grid element wrap the container in a Border; margin is always outside.
- `<img>` takes an `.svg` source only; `<svg>` inline, raster images, `url()` and icon fonts are rejected.
- A class style that sets the color of an `f-color-rect` can shift sibling text by a pixel or two; set it on the element with `-f-Color: resource(token.color)`.

## Units

`px`, `rem`, plain numbers, `fr` in grid tracks, `ms` and `s` in animations. Percentages, `em`, `vw` and `vh` are rejected.

## Diagnostics

Every error has a stable code, a source location and a help line.

- `FHTML1001` syntax error
- `FHTML1002` unknown element
- `FHTML1003` unknown attribute
- `FHTML1004` rejected construct
- `FHTML1005` structure error
- `FHTML1006` link target problem
- `FHTML2001` unknown CSS property
- `FHTML2002` unsupported unit
- `FHTML2003` invalid value
- `FHTML2004` unsupported selector
- `FHTML2005` rejected property
- `FHTML3001` an f: property has an HTML or CSS spelling (hint, not an error)
